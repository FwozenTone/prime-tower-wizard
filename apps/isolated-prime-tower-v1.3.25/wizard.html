Choose a project to list its plates.

Existing generated towers are shown but cannot be selected. Each selected plate gets its own tower. If a plate fails, the remaining plates are still attempted.

Slicer

Each branch remembers its own application location. The selected branch is used for both slicing and opening the project.

Save your print-quality settings in the 3MF first. Variable layer heights are copied from the reference slice. Do not change layer settings after generating the tower. Turn off arc fitting. Independent layer grids must fit every tower nozzle’s layer-height limits. The tower gets the selected outer brim with zero gap. Other plates remain in the output project. The final project is saved beside the original as name_tower_v1.3mf (or the next available number). Unless you choose to keep the working folder for debugging, working files are removed after saving and only the final 3MF remains. The original is never overwritten.

Each selected plate has independent tower settings. Defaults: width 30 mm, ribs 5 mm, brim 5 mm, minimum purge 5 mm³, and automatic outer-wall filament. Selecting a new project resets all tower settings. A manual outer-wall filament must be used on that plate; automatic chooses a rigid filament used there.

Guided manual export
